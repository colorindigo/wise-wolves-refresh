# Wise Wolves · обновление суммы

Риг главной Wise Wolves: оттягивание экрана вниз и обновление суммы. Открывается одной страницей, все картинки и шрифты внутри файла.

- `index.html` — волна: цифры размываются, опускаются и гаснут.
- `v1/index.html` — по цифре, как в секции Figma `Main · refreshing · motion v1`: цифры уходят справа по одной вслед за оттяжкой, новая сумма набирается по цифре.

Режим переключается и на странице, в «Параметрах».

Собирается из `experiments/refresh/index.html` скриптом `build-share.py`.
